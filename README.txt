DPMA – párování řidičského počítače a vnitřní tabule

1. Rozbal ZIP.
2. Nahraj index.html, style.css, script.js a lines.json do stejné složky svého GitHub Pages repozitáře. Nahraď staré soubory.
3. Počkej, až se GitHub Pages nasadí.
4. Na zařízení řidiče otevři HTTPS adresu DPMA a zadej dpma1.
5. Na druhém zařízení otevři tutéž adresu a zadej dpma2.
6. Spusť nejdřív DPMA1 a potom DPMA2. Obě zařízení musí mít internet.
7. Na DPMA1 zadej kód linky, např. 07401. DPMA2 zobrazí linku, cíl, seznam zastávek a zvýrazní aktuální zastávku.
8. Stisknutí + na DPMA1 posune aktuální zastávku i na DPMA2.

Poznámky: Používá se PeerJS načítaný z internetu. Pevná ID znamenají, že současně používej pouze jedno DPMA1 a jedno DPMA2. Není to zabezpečený systém pro veřejný provoz. Pokud se spojení nepovede, obnov obě stránky a spusť nejdřív DPMA1.
